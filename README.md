# Zomato Restaurant Data Analysis and Price Prediction

This notebook analyzes Zomato restaurant data and builds a simple linear regression model to predict the average cost for two people.

The key steps include:

1.  Loading and cleaning the data.
2.  Selecting relevant features.
3.  Creating a new feature based on the average cost per cuisine.
4.  Encoding categorical features.
5.  Training a linear regression model.
6.  Evaluating the model using R-squared and Mean Squared Error (MSE).

The model achieved an R-squared score of approximately 82.48% and an MSE of around 45931.21.
